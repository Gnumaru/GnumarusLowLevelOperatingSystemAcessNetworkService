# FEATURES_SUMMARY

Server version v0.10.0 (no web frameworks):

- The **Go port (`go/`) is the reference implementation**; the same contract is implemented in nine runtimes (go/rust/python/nodejs/dotnet/php/ruby/cpp/kotlin). Protocol ambiguities resolve in Go's favor, `tests/run_all.py` runs the Go server by default, and new features land there first.
- Every port builds a binary named `GnumarusOSBridge` (Kotlin: `build/install/GnumarusOSBridge/bin/GnumarusOSBridge`; .NET: `publish/GnumarusOSBridge.dll`)
- CLI server (`go/GnumarusOSBridge`): `[--host H] [--port P] [--token TEXT] [--auth|--no-auth]` — every setting also via `GNUMARUS_*` env, stdin key=value, or `config.cfg` next to the binary (precedence: CLI > env > stdin > file > default)
- Token auth required everywhere except `GET /`, `GET /api/help` and the OAuth2 loopback callback (Bearer header or `?token=`; `--no-auth` disables explicitly)
- Loopback-only: `--host` accepts just `localhost`, `127.0.0.0/8` or `::1` (anything else is a config error, exit 2 — other machines can never reach it); every request's `Host` header must name loopback too (port ignored), else `403 {"error":"forbidden"}` before auth and before any side effect, on all methods/routes/OPTIONS/WS-upgrades
- Open CORS on all responses + OPTIONS preflight (`Access-Control-Allow-Origin: *`)
- `GET /` — service index with version and help pointer
- Wire format: JSON carries only string/array/object. Numbers, booleans and nulls travel as tagged strings (`i:<int>`, `f:<float>`, `b:true|false`, `null`); fixed vocabulary and free text stay raw; sqlite row cells and `params` values are fully tagged (strings take an `s:` prefix). Query params stay plain.
- `GET /api/help` — full route catalog: the same **24 routes** on all nine ports, including the 5 Gmail OAuth2 service routes: url, name, description, params
- `GET /api/dir?path=...` — list directory contents with per-entry metadata (`name, path, type, size, atime, mtime, ctime, crtime, mode`; `crtime` null where the OS lacks birth time; `ctime` is the real inode-change time, not a zero placeholder)
- `GET /api/file?path=...[&encoding=auto|text|base64][&raw=1]` — read text and binary files (JSON auto/base64/text modes + raw bytes mode)
- `POST /api/file?path=...` — create file, empty or with initial data (JSON `{content, encoding}` or raw bytes); 201 on success, 409 if exists
- `PUT /api/file?path=...` — overwrite file content, text or binary (same body rules); 404 if missing
- `POST /api/shell` — run a bash string (`bash -c`), JSON `{command, timeout?, cwd?, max_stdout?, max_stderr?, stdin?, stdin_encoding?}`; returns `{command, cwd, returncode, stdout, stderr, timed_out, stdout_truncated, stderr_truncated, max_stdout, max_stderr, stdin_bytes}`; stdin piped in (text or base64, EOF when done); commands run fully, response streams truncated (default 1 MB each, 100 MB cap); timeout kills the process group, rc 124
- `POST /api/sqlite/create?path=...` — create a new SQLite file (409 if exists); 201 `{path, absolute_path, size, sqlite_version}`
- `POST /api/sqlite/query?path=<db>` — run one SQL statement, JSON `{sql, params?, timeout?, readonly?}`; SELECT-style → `{columns, rows, rowcount}` (BLOBs as base64), writes commit → `{rowcount, lastrowid}`; fresh connection per request
- `POST /api/socket/open` — open a TCP connection to a peer, hold it as a session: JSON `{host, port (i:), timeout?, tls? (b:), sni?, ca_pem?}` → 201 `{id, kind (tcp|tls), host, port}`; `tls:b:true` handshakes immediately (implicit TLS, verified against system roots + optional `ca_pem`, SNI defaults to host); connect/TLS failures are 400 with the engine error text (see §34)
- `POST /api/socket/starttls?id=<id>` — upgrade a plaintext session to TLS in place (optional JSON `{sni?, ca_pem?}`) → 200 `{id, kind: tls}`; failed handshakes keep the plaintext session; refused while WS-attached/recv-pending/already-TLS (see §34)
- `POST /api/socket/send?id=<id>` — write bytes (JSON `{content, encoding}` or raw bytes) → `{id, bytes}`
- `GET /api/socket/recv?id=<id>[&timeout=][&max_bytes=]` — long-poll read → `{content (base64), bytes, eof, timed_out}`; empty content + `eof` after the peer closed, + `timed_out` when nothing arrived in time
- `POST /api/socket/close?id=<id>` — close the session → `{closed}`; unknown ids are 404, idle sessions expire (300 s), max 128 open
- `GET /api/socket/ws?id=<id>` — attach a real WebSocket to a session (`Upgrade: websocket`, token via `?token=`): after 101, WS message payloads flow client→TCP (text as UTF-8) and TCP bytes come back as binary frames; ping auto-pong; close from either side ends the whole session; HTTP send/recv refused while attached. Supported on all nine ports (24 routes each); the Kotlin port owns its TCP layer (hand-rolled HTTP/1.1 server over raw `ServerSocket`) so the upgrade can hijack the connection like Go/Python/Ruby/PHP
- Transparent bytes both ways (e.g. browser SMTP/IMAP through the local service); same token auth; localhost-bind WARNING like shell (open network proxy by design)
- `POST /api/oauth2/start` — start an OAuth 2.0 Authorization Code + PKCE session for a mail provider (Google defaults): JSON `{client_id, client_secret?, auth_url?, token_url?, scope?}` → 201 `{id, auth_url, redirect_uri, scope}`; the service mints state + PKCE S256, keeps the client secret, and holds the refresh token (see §36)
- `GET /api/oauth2/callback?code=&state=` — loopback redirect target (open route, no token, correlated by the random state): the service exchanges the code for tokens server-side and renders a small self-contained HTML page; `GET /api/oauth2/poll?id=` reads the state and hands back the short-lived access token (never the refresh token), `POST /api/oauth2/refresh?id=` mints a new access token, `POST /api/oauth2/close?id=` drops the session
- The OAuth2 routes exist on **all nine ports** (go, rust, python, nodejs, php, ruby, kotlin, dotnet, cpp); all OAuth tests run on every port
- `php/` runs a single ReactPHP event-loop process with in-memory socket sessions (no daemon); `filemanager.html` gains a socket panel + reusable `SocketSession` JS helper class
- `GET /api/sysinfo` — OS/host info, no params: `{system, system_name, release, version, machine, processor, hostname, cpu_count, distro?, windows?, mac?}`. Managed runtimes also report the version of the runtime that executes them (`python_version`, `node_version`, `php_version`, `ruby_version`, `jvm_version`, `dotnet_version`); the native runtimes (Go, Rust, C++) report **no** version field
- `DELETE /api/file?path=...` — delete a file; 400 if path is a directory
- `DELETE /api/dir?path=...` — rmdir equivalent, empty directories only; 400 if not empty
- `DELETE /api/dir/shallow?path=...` — delete a shallow directory (files, symlinks and empty subdirectories only); 400 if it contains a non-empty real subdirectory. Also reachable as `DELETE /api/dir?path=...&shallow=1` and under the path aliases `/api/shallow_dir` and `/api/dir_shallow` (advertised in the help catalog)
- JSON error responses (400/401/403/404/405/409) for all failure cases
- `tests/` — stdlib-only regression suite (241 tests against Go or any other port, incl. 12 TLS tests and 14 Gmail OAuth2 tests that skip only when a port lacks the capability; zero skips on the Go reference): `python3 tests/run_all.py` mints a token, starts the reference Go server with `--token`, runs everything, stops it (`--server-cmd/--server-cfg` select another port). Helpers enforce the wire invariant on every response (no int/float/bool/None instance anywhere after parsing) and offer `tv()`/`ti()`/`tf()` for tagged assertions. The suite also asserts the exact 24-route catalog, the `shallow` parameter of `delete_directory`, the single runtime-version field of `/api/sysinfo`, and that `ctime` matches `stat(1)`. `tests/test_oauth2.py` drives the whole OAuth flow through a local fake Google (PKCE S256, code exchange, refresh, error/validation paths); `tests/js_emailclient_auth.js` unit-tests the showcase SASL payload + continuation abort, the SORT/SEARCH/FETCH response parsers and the OAuth auto-connect under node.
- `showcase/emailclient/` — pure read-only IMAP inbox (index.html + styles.css + app.js, no build, no external URLs): provider presets (gmail/outlook/icloud/yahoo/proton-bridge + custom; TLS presets open with `tls:true`, verified in the proxy service), two auth modes — Password (`LOGIN`) or Google OAuth2 (`AUTHENTICATE XOAUTH2`, the service does the OAuth dance so no external URL ever appears in the page; picking OAuth2 selects the Gmail preset and a finished sign-in auto-connects, landing on the inbox) — read-only EXAMINE, paginated UID listing (whole-response SORT/SEARCH parsing so Gmail's unsolicited `* CAPABILITY` and missing SORT are handled), BODY.PEEK open with MIME walk; uses only the socket proxy (WS preferred, HTTP fallback); no send/delete/flag commands exist (see §33); tested by `tests/test_showcase_emailclient.py`
- `showcase/filemanager/` — pure multi-file web file manager (index.html + styles.css + app.js, no build, no external URLs): server/token bar with localStorage, help-driven caps, breadcrumbs, dir table with full entry metadata (type/size/atime/mtime/ctime/crtime/mode), text preview/edit/save, binary download, create/delete file, delete empty dir, sysinfo line; uses only the file/dir/help/sysinfo API functions (see §32); tested by `tests/test_showcase_filemanager.py`
- `filemanager.html` — single-file web file manager (inline CSS+JS, no build): token field with localStorage, 401 unauthorized state; works hosted anywhere and via `file://`, capability-driven from `/api/help` (list/navigate, text view/edit, download, create, delete, shell console, SQLite, socket panel with WebSocket toggle); errors in-UI, operations blocked when offline; works against any port (same contract)
- `python3/` — Python implementation (stdlib only, no deps):
  flat modules (`server.py` thin entry + `version/tags/config/fsutil/times/routes/handler/handler_fs/handler_shell/handler_socket/handler_socket_ws/handler_sqlite/handler_oauth2/handler_sysinfo.py`); same 24 routes/flags/precedence (incl. `socket_ws` via manual 101 + hijacked connection, `socket_starttls` via `ssl` stdlib, and the 5 OAuth2 routes); run `python3 python3/server.py`; reports `python_version`
- `kotlin/` — full Kotlin/JVM port of the service (Gradle + Gson + sqlite-jdbc + JNA; stdlib JDK otherwise): `kotlin/src/main/kotlin/{Main,Config,Api,Http,SocketWs}.kt`; hand-rolled HTTP/1.1 server over raw `ServerSocket` (own TCP layer, one request per connection, so `socket_ws` can hijack the raw socket; RFC 6455 ported from Go) — the JDK `HttpServer` is gone; same 24 routes (`socket_ws` + `socket_starttls` + 5 OAuth2), same CLI flags, same config precedence, reports `jvm_version`; TLS via JVM `SSLSocket` + manual hostname check; build `./kotlin/build.sh` (needs Gradle 7+), run `kotlin/build/install/GnumarusOSBridge/bin/GnumarusOSBridge`
- `php/` — full PHP port of the service (composer deps: react/socket + react/event-loop + react/child-process): `php/server.php` (CLI/config/single-process ReactPHP loop) + `php/src/{Config,Api,Http,HttpServer,SocketStore,WsProto,SocketProto}.php`; same 24 routes/flags/precedence (incl. 5 OAuth2 and `socket_ws`: manual HTTP/1.1 server on `react/socket` with hand-rolled RFC 6455, like Go/Python; `socket_starttls` via blocking `stream_socket_enable_crypto`); in-memory socket sessions (no daemon), async shell via child-process (setsid+killpg parity), `crtime` null on Linux (FFI blocked), times are ints, reports `php_version`; build `./php/build.sh`, run `php php/server.php`
- `ruby/` — full Ruby port of the service (Ruby 3.3 stdlib only; one vendored gem: `sqlite3` under `ruby/vendor/gems`, gitignored): `ruby/server.rb` (CLI/config/boot) + `ruby/lib/gnumarus/{api,config,http,fsops,shell,sqlite,sock,sock_ws,oauth2,sysinfo,routes,tags,util,statx}.rb`; hand-rolled HTTP/1.1 server over raw TCP (so `socket_ws` hijacks, manual RFC 6455, hand-rolled accept key), same 24 routes/flags/precedence (incl. 5 OAuth2); TLS via `OpenSSL::SSLSocket` + manual RFC 6125 hostname check (built-in check misses IP SANs), real birth time via the `statx` syscall through Fiddle (`File::Stat#birthtime` is unimplemented here), `bash -c` in its own process group (KILL to `-pid`), 503 when the sqlite3 gem is unavailable, reports `ruby_version`; build `./ruby/build.sh`, run `ruby ruby/server.rb`
- `nodejs/` — full Node.js/TypeScript port of the service (devDeps only: typescript + @types/node; runtime is node core incl. `node:sqlite`): `nodejs/src/{server,config,api,tags}.ts` compiled to `dist/`; same 24 routes/flags/precedence (incl. 5 OAuth2 and `socket_ws` via the `upgrade` event, `socket_starttls` via `node:tls`); detached process groups for shell kill parity, real birth time via `birthtimeMs`, reports `node_version`; build `./nodejs/build.sh`, run `node nodejs/dist/server.js`
- `dotnet/` — full C#/.NET port of the service (one NuGet dep: Microsoft.Data.Sqlite; HttpListener/JSON/FS all in the shared framework): `dotnet/{Program,Config,Tags,Api,Sql}.cs`; same 24 routes/flags/precedence (incl. 5 OAuth2 and `socket_ws` via `HttpListenerContext.AcceptWebSocketAsync`, verified on Linux; `socket_starttls` via `SslStream` + custom chain/hostname check); setsid+libc-killpg shell parity, real birth/ctime via statx P/Invoke, reports `dotnet_version`; build `./dotnet/build.sh`, run `dotnet dotnet/publish/GnumarusOSBridge.dll`
- `go/` — REFERENCE port (one module dep: modernc.org/sqlite, pure Go; everything else stdlib): `go/{main,config,tags,api,write,shell,socket,socket_ws,oauth2,sqlite,sysinfo,routes,statx}.go`; the same 24 routes as every other port (incl. the 5 Gmail OAuth2 routes and `socket_starttls`); detached process groups for shell kill parity, birth/ctime via raw statx syscall (STATX_BTIME|STATX_CTIME), real bound params; `tests/run_all.py` runs it by default; build `./go/build.sh`, run `go/GnumarusOSBridge`
- `rust/` — full Rust port of the service (deps: serde_json + sqlparser + rusqlite/bundled + libc + openssl; std for the rest): `rust/src/{main,config,tags,api,http,codec,sql,sqlite_api,shell,socket,socket_ws,oauth2,sysinfo,help,timex}.rs`; same 24 routes/flags/precedence (incl. `socket_ws`: upgrade intercept in the hand-rolled server, hand-rolled SHA-1; `socket_starttls` via the `openssl` crate); `setsid`+`kill(-pgid)` shell parity, real birth/ctime via raw `statx` (256-byte ABI asserted); build `./rust/build.sh` (target-dir `~/.rust_target_dirs/...`, binary copied to `rust/bin/GnumarusOSBridge`, gitignored), run `rust/bin/GnumarusOSBridge`
- `start.sh` — launcher: `./start.sh --runtime <name> [server args...]` (`python|kotlin|php|ruby|nodejs|go|dotnet|rust|cpp`); the first `--runtime` selects the implementation (alias `--runtime=<name>`), everything else is forwarded verbatim — `--port` is reserved for the TCP port; stdin untouched (`exec`); missing artifact → build instructions + python fallback; unknown/missing name → usage, exit 2
- `start.bat` / `start.ps1` — same launcher for Windows cmd / PowerShell 5.1 (see §26)
- `cpp/` — full Modern C++ port of the service (vendored: nlohmann/json + SQLite 3.54 amalgamation; std C++20 + POSIX): `cpp/src/{main,config,tags,codec,http,api}.cpp` + handler `.inc` TUs + `sysinfo/routes` data; same 24 routes/flags/precedence (incl. `socket_ws` via an `http_serve` hijack hook, hand-rolled SHA-1, exactly-once fd discipline; `socket_starttls` via system OpenSSL); fork+setsid+killpg shell parity, raw `statx` birth/ctime; build `./cpp/build.sh` (cmake `build/` + copy to `cpp/bin/GnumarusOSBridge`), run `cpp/bin/GnumarusOSBridge`
